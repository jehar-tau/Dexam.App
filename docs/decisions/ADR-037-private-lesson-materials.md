# D-037: Private lesson materials

Status: Option B approved by owner, 2026-10-14; fictional/local implementation only

The owner selected the bounded private lesson-file policy below. Options A/C are alternatives, not implementation authority. Production capacity and verified cleanup ownership remain gates. D-031 A and D-036 A remain unchanged.

## Question

Should students be able to download private files attached to their assigned lessons, beyond the text-first lessons and existing assignment attachments?

## Why this needs your decision

DW-009 remains deferred. D-016 approved assignment attachments only, not lesson storage, access or retention. Adding lesson files changes student content and storage obligations. D-031 A and D-036 A remain unchanged.

## Options

### A — Keep text-first lessons

Keep existing lesson text and assignment attachments; defer separate lesson uploads. No new vendor spend or storage scope. Reversible later, but staff must use assignment attachments for existing PDF/image material.

### B — Bounded private PDF/image lesson files (recommended)

Allow at most five PDF/JPEG/PNG/WebP files, at most 10 MB each, per lesson. Reuse the current stack and current offering-scoped content edit/publish capabilities. Validate untrusted files and use opaque private object keys; authorized downloads only, no executable inline content or public URLs. Images use conservative compression; PDFs remain unchanged. Text remains first-class.

Draft files may be replaced/removed; publication pins the exact files and later changes require a new curriculum version. Students access only their own active, assigned published coursework; closeout/revocation denies new downloads. The work archive does not gain lesson access. No new Teacher, Sales or operator authority.

Unattached abandoned uploads become cleanup-eligible after 30 days. Attached draft files stay until deliberately removed or their draft is deleted. Published files remain while their version is referenced by an active enrolment/cohort; otherwise physical deletion becomes eligible 12 months after retirement, with no early-deletion override. Shared/copy references must prevent deletion while legitimately in use. Production activation requires verified cleanup ownership and capacity review. No personal-data import or real files are authorized now.

No additional vendor or paid plan for fictional/local implementation. Existing finite storage/egress allowances apply; no promise of free arbitrary scale. Larger formats or limits require a later decision. Reversible for future drafts; published file/history semantics must be preserved.

### C — Discover richer media first

Plan video/audio/ebooks or a richer lesson editor before building. Define rights, accessibility, delivery/storage cost, retention, provider and budget. Discovery has no additional vendor spending; implementation and any paid service require separate approval. Larger scope; no new file uploads meanwhile.

## Recommendation

B covers the existing PDF and visual teaching-material use case without a new vendor or broader media stack. A remains appropriate if text plus assignment files is sufficient for the current pilot.

## What can continue while pending

Existing coursework, assignment attachments, feedback and alerts remain unchanged. No lesson file bucket, upload interface, permission or retention job is implemented before selection.
