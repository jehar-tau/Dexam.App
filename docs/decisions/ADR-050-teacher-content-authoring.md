# D-050 — Teacher content authoring, named attachments and draft topic removal

Status: Option B approved 2026-10-18. Supersedes D-031 A only for explicitly scoped content authoring/publication; broader teacher reader/roster remains deferred. No real account grants or production operations authorized.

## Requested outcome and current evidence

Owner requests Content within the Teacher portal, multiple named topic/instruction and assignment attachments, topic deletion, and confirmation that Distribution lists published assignments. Existing Content resides in staff operations with separate scoped editor/publisher capabilities. Lessons and assignments already permit private PDF/JPEG/PNG/WebP files, five per item and 10 MB each, but use filenames rather than independent descriptive labels, upload one at a time and omit lesson files in preview. Topic editor has no delete control. Distribution queries published assignment versions within current authorization; publication and student release remain separate.

## Options

### A — Teacher portal entry, existing permissions only

Add the Content entrance for teachers who already independently hold content editor/publisher capabilities. Add named multiple lesson/topic materials and assignment attachments within the existing file limits. Add confirmed removal of draft topics with explicit impact preview; block removal while assignment links remain. Published topics remain immutable; remove them only from a new draft version, never from already assigned versions. No automatic Teacher-role authoring authority. ₹0 added vendor spending for local fictional work; some teachers will not have Content until separately provisioned.

### B — Explicit offering-scoped teacher authoring and publication (recommended)

Provide Teacher Content to teachers explicitly granted authoring and/or publication for each offering; Teacher role alone is insufficient. Editors can create/edit drafts and attach named files; publication requires a separate explicit capability and deliberate release action. The same teacher may hold both capabilities. Reuse current versioning and file policies, with multi-select upload and per-file descriptive names shown to authorized students/reviewers. For topic-only material, use a clearly identified lesson/material container under the topic rather than a second incompatible file store. Confirmed draft-topic removal previews affected lessons/materials and blocks linked assignments until unlinked deliberately. Published/history snapshots and referenced bytes remain protected. Published assignments appear in the existing authorized Distribution workspace without granting teachers student-release authority. ₹0 added vendor spending for fictional/local work; additional storage remains subject to existing limits. Revocable grants; published history is retained.

### C — All teachers author/publish across all offerings

Global Teacher role would grant broad content editing/publication. Same attachment and draft-only deletion safeguards as B, but greater risk of cross-course mistakes and exposure of drafts. ₹0 additional vendor spend for local work, substantially broader authority; not recommended. No published-history deletion or student-distribution authority implied.

## Boundary

All choices exclude production, real data, paid services, live account provisioning, new file formats/limits, automatic student distribution and hard deletion of published history. Independent security review and permission/revocation, private-file, versioning, dependency and browser tests are required before merge. Current user request establishes desired functionality, but does not resolve which teachers may publish which offerings; do not infer a global grant.
