# F018 — Teacher teaching workspace

Status: Draft — D-031 required; no implementation authorized
Risk: Yellow

## Outcome

Let teachers prepare from the same published curriculum and released assignment material students use, without granting content editing, access to other programs or unrelated student personal information.

## Proposed Option B boundary

Read-only current explicitly assigned offering scope; active person/live provider session/employee membership/Teacher role and current teaching authority all required. Read published curriculum versions actually used by eligible current cohorts or cohort-free enrolments in that offering, ordered sections/topics/lessons, and released assignment definitions, approved private reference files and published evaluation guidance. Version discovery must not expose individual enrolment records. Existing submission-review links preserve their own authorization.

No raw contacts/CRM, general student roster, attendance, class calendar/cancellation, automatic notification or distribution, draft curriculum, publishing/editing, new AI/feedback authority, recovery or staff role changes. No global-role wildcard. Ended/revoked/expired scope, suspended staff/person, unpublished/cross-offering material or unsafe downloads fail closed.

Use the existing strict design-system primitives with loading/error/empty/mobile/keyboard states. Fictional preview is for rendering only; server permissions are never bypassed. No external service or real personal data.

## Proposed verification

Teacher scope matrix against Student, Sales, ordinary Admin, content author and unrelated Teacher; live-session deletion/revocation; suspension/time windows; published/current-pinned version discovery without roster disclosure; private material purpose/expiry; cross-offering and unpublished denial; immutable material reads; review-link authority; desktop/mobile browser journeys; minimum response fields and no credentials in artifacts.

## Deferred scope

Roster/schedule/attendance and new notifications require separate approved fields/workflows. DW-010 tracks this proposed reader; DW-007 enrolment lifecycle, DW-008 progress and DW-011 curriculum migration remain independent decisions. No D-031 answer is recorded yet.
