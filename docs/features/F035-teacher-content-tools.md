# F035 Teacher content tools

Status: D-050 Option B approved 2026-10-18; local implementation/acceptance complete, required PR CI pending. Risk Red.

Teachers with explicit existing offering-scoped editor/publisher capabilities can use `/teacher/content`; `/staff/content` remains supported. A Teacher role alone grants neither editing nor publication. The portal entrance recognizes Teacher role and content authority for the same offering, including scoped teachers without review authority. The workspace filters authorized offerings and separates edit/publish controls; API/RLS checks remain authoritative. No real account grants are created by this feature.

Lesson/topic and assignment materials support multi-file selection, within existing PDF/JPEG/PNG/WebP limits of five files and 10 MB each. Each reference can have a descriptive name, defaulting to the original filename. Descriptions are draft-only metadata, never object names or shared-byte mutations. Topic-only files use a normal `TOPIC_MATERIALS` lesson container, visible through existing coursework. Curriculum clones retain per-reference names. Assignment uploads retain tracked reservations, retries and existing cleanup safety; no new deletion worker or storage policy for upload is activated.

Named assignment references are visible in the student assignment and existing teacher review context. Downloads require attached metadata and current existing assigned-version/content authority, with short-lived private signed URLs. Unassigned students, other offerings, revoked users and unrelated staff are denied. This does not implement the broader teacher curriculum reader or full rubric screen.

Topic removal is draft-only, previews lesson/file/link counts and requires confirmation. Any assignment link blocks removal. An explicit unlink action is available only for draft assignment links; published links cannot change. Unlinking does not delete the assignment. Removal serializes child changes, detaches references before deleting lessons/topic, retains shared bytes and audits identifiers/counts. Published curriculum and students' pinned history remain unchanged. A changed impact requires preview again. No general published-topic deletion or force-unlink operation exists.

Publishing and Distribution remain separate capabilities/actions. All published assignments within the operator's authorized offerings are eligible for the existing Distribution list, regardless of author. Publishing alone creates no student release, course migration or access.
