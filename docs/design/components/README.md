D-064 / [Discovery 1.0](../DISCOVERY.md) supersedes the historical visual source in existing specifications. Their component semantics, states, and accessibility rules continue to apply. Buttons now use 6px corners, cards 10–12px, green primary actions, and the Discovery tokens. Empty states use the approved decorative artwork by default. Shell roles and navigation behavior remain unchanged.
