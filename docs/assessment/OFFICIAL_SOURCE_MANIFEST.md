## Required record per source file

- Exam, year, paper/version and canonical official URL
- Retrieval timestamp and SHA-256 digest
- Page or source location for every question and asset
- Question type, section and official marking rule
- Official answer-key URL/digest where available
- Extraction method and OCR confidence
- Human verification status and verifier identity
- Correction/version history
- Rights/attribution note and publication approval state

The public Roughworks count of **1,689 PYQs** is a comparison target only. It does not prove source completeness, answer correctness or permission to copy their processed records.
