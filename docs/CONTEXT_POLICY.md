# Context Policy

Use map → search → open relevant source → work.

- Begin with `CURRENT_STATE.md` and `INDEX.md`.
- Search filenames and text before opening documents.
- Load only the active feature specification, relevant sections of core documents, and directly related ADRs.
- Do not bulk-read documentation, knowledge, generated files, dependencies, or large source assets.
- Treat compact indexes and metadata as routing tools, not substitutes for the authoritative source.
- A handoff describes task, branch, completed work, remaining work, verification, constraints, and next step; it does not paste conversation history.
- Durable facts belong in canonical documentation. Temporary task state may live in an issue, branch, PR, or uncommitted `HANDOFF.md`.
